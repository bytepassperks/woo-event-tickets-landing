Documentation

Get Running in 5 Minutes

1

Install Plugin

Upload ZIP to WordPress → Plugins → Add New → Activate. Creates 10 optimized tables automatically.

wp plugin install woo-event-tickets.zip --activate
2

Create Event

Event Tickets → Events → Add New. Set date, venue, capacity, branding colors.

[ticket_event id="123"]
3

Add Ticket Types

Set prices, early bird, quantities. Auto-creates WooCommerce products synced bidirectionally.

[ticket_types event_id="123"]
4

Sell & Scan

Customers buy via WooCommerce. Tickets auto-generated on payment. Staff scan at venue.

[ticket_scanner event_id="123"]
